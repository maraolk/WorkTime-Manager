# UX-концепция

## Персоны

### Персона 1: Аня, фриланс-разработчик

- Цели: быстро фиксировать время по клиентским проектам, экспортировать отчет за период.
- Важно в первые 30 сек: увидеть дневной прогресс, активный таймер и последние записи.

### Персона 2: Иван, тимлид небольшой команды

- Цели: сравнивать плановое и фактическое время по задачам, быстро находить перерасход.
- Важно в первые 30 сек: увидеть суммарные часы, отклонение от плана и фильтр по проекту.

## User Stories

1. Как исполнитель, хочу запускать таймер по проекту и задаче, чтобы не вводить время вручную.
   - Шаги: выбрать проект, выбрать задачу, нажать старт, добавить описание, остановить таймер.
   - Done-критерий: после остановки появляется новая запись времени.

2. Как пользователь, хочу вручную добавить запись времени, чтобы учесть работу, которую забыл запустить таймером.
   - Шаги: открыть форму, заполнить дату, проект, задачу, длительность и описание, сохранить.
   - Done-критерий: запись отображается в списке и влияет на статистику.

3. Как менеджер, хочу отфильтровать отчет за период и экспортировать CSV, чтобы отправить клиенту.
   - Шаги: выбрать даты, проект, сортировку, проверить итоги, нажать экспорт.
   - Done-критерий: скачивается CSV-файл с записями, суммарными часами и понятным названием по периоду.

4. Как пользователь, хочу видеть предупреждения перед удалением и статус план/факт, чтобы не потерять данные и быстро заметить перерасход.
   - Шаги: открыть список записей или отчет, проверить статус проекта, удалить только после подтверждения.
   - Done-критерий: удаление требует подтверждения, а проект получает статус on track / close to plan / over planned time.

## Дизайн-система (Taiga UI 5)

- Используемые компоненты: `TuiRoot`, `TuiButton`, `TuiIcon`, `TuiLoader`, `TuiTitle`.
- Кастомные компоненты: карточка метрики, форма записи времени, таблица записей, панель фильтров, форма управления проектами и задачами, индикатор дневной цели.
- Визуальный стиль: рабочий dashboard без маркетингового hero, плотные таблицы, спокойные акценты, быстрые действия на первом экране.

## Приоритеты

- Первый экран: дневная цель, активный таймер, быстрый выбор проекта/задачи, последние записи.
- Вторично: управление проектами и задачами, расширенные фильтры, экспорт, настройки дневной цели, предупреждения об удалении.
- Сознательно убрано: командные роли, биллинг, интеграции с внешними трекерами.
